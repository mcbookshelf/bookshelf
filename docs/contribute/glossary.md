# 📘 Glossary

These words have a specific meaning in this project:

---

```{include} ../_templates/definitions.md
```

:::{list-table} Contributor concepts
*   - **Experimental**
    - A feature that isn't ready. Only nightly builds include it.
*   - **Group**
    - A folder that contains several features and the files that they share. The features of a group take the same inputs and write the same outputs.
*   - **Private**
    - A file that only its feature or group can use. Functions are always private. Other files are private when they have a `_` prefix.
*   - **Released**
    - A module whose version reached `1.0.0`.
:::
