## 📦 [Bookshelf - 4.2.0](https://github.com/mcbookshelf/bookshelf/releases/tag/v4.2.0)

> **🎬 The Animation Update!**
>
> *Adds new animation and finite state machine modules, and support for Minecraft 26.3.*

> **🎨 Color module Update**
>
> *Adds compute and alpha support*


Bookshelf is now based on **Minecraft 26.3**.

- <abbr title="New Features">✨</abbr> **[#572](https://github.com/mcbookshelf/bookshelf/pull/572)** - Migrate resources to Minecraft 26.3.


### `🎬 bs.animation`

- <abbr title="New Modules">🎉</abbr> **[#512](https://github.com/mcbookshelf/bookshelf/pull/512)** - Added a new `bs.animation` module.


### `🔄 bs.fsm`

- <abbr title="New Modules">🎉</abbr> **[#480](https://github.com/mcbookshelf/bookshelf/pull/480)** - Added a new `bs.fsm` module to describe behaviors as states and transitions, and run them on entities or globally.


### `❤️ bs.health`

- <abbr title="Enhancements">⚡</abbr> **[#577](https://github.com/mcbookshelf/bookshelf/pull/577)** - Optimized health computation using new number providers.
